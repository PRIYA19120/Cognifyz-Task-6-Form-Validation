# Cognifyz Task 6 – Form Validation

## Project Overview
This project is created as part of the Cognifyz Technologies Front-End Development Internship. It is a user-friendly form with input fields and client-side validation using HTML, CSS, and JavaScript.

## Features
- User registration form with Name, Email, Password, and Confirm Password fields.
- Checks that required fields are filled in.
- Validates the email format.
- Checks password and confirm password matching.
- Displays validation messages when input is incorrect.
- Responsive and clean user interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Fill in the form to test the validation features.
